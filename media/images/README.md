# Images Directory

This directory contains all image files used in the Python-Challenges repository.

## Subdirectories

- **screenshots/** - Screenshots of project outputs and results
- **diagrams/** - Flowcharts, architecture diagrams, and visual explanations
- **demos/** - Demo images and example outputs

## Usage

To reference images in your markdown files:

```markdown
![Alt text](media/images/screenshots/your-image.png)
```

From within a project subdirectory:

```markdown
![Alt text](../media/images/screenshots/your-image.png)
```

## Guidelines

- Use descriptive filenames (e.g., `sorting-algorithm-output.png`)
- Compress images before uploading to keep file sizes small
- Recommended formats: PNG for screenshots, JPG for photos
- Maximum recommended size: 10MB per image

For more details, see [MEDIA_GUIDE.md](../../MEDIA_GUIDE.md)
