## 📁 Repository Structure

- **`media/`** - Images and videos for documentation and demos
  - `images/` - Screenshots, diagrams, and demo images
  - `videos/` - Demo and tutorial videos
- **`projects/`** - Python project directories (to be added)

## 📸 Including Images and Videos

This repository supports including images and videos to document your Python projects. You can:

- Add **screenshots** of your project outputs
- Include **diagrams** to explain algorithms or architectures
- Upload **demo videos** showing your projects in action
- Create **tutorial videos** explaining your code

### Quick Start

1. **Add your media files** to the appropriate directory:
   - Images: `media/images/{screenshots,diagrams,demos}/`
   - Videos: `media/videos/{demos,tutorials}/`

2. **Reference them in markdown**:
   ```markdown
   ![Project Screenshot](media/images/screenshots/my-project.png)
   ```

3. **For videos**:
   ```html
   <video src="media/videos/demos/demo.mp4" controls width="600"></video>
   ```
